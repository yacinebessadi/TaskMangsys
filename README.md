# TaskMangSys
Task Management System 📝✅ A simple Tkinter-based task management system 



Task Management System 📝✅
USTHB – Computer Science Faculty (2024-2025) - Mini-Project
Module: DSA - L2 ACAD B

This project is a task management system built as part of a university assignment at USTHB. It is implemented using a singly linked list to manage tasks efficiently.
📌 Features:

    Task Insertion: Adds tasks in order of priority (1-5, higher priority first).
    Task Deletion: Removes a task by its unique identifier.
    Update Status: Modifies the status of a task (Pending, In Progress, Completed).
    Display Tasks: Shows all tasks.
    Search by Priority: Finds and displays tasks with a specific priority level.

This project was developed using Python and Tkinter for the GUI
